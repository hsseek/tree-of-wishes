# 소원의 나무 — 인스타그램 성장 플레이북

타깃: 한국 사용자 · 예산: 무료(오가닉) · 목표: 인스타 → `tree-of-wishes.fyi` 유입 + 소원 작성/공유.

이 문서는 4개 전략 축의 **운영 매뉴얼**입니다. 그중 ①영상(릴)은 3단계 파이프라인으로
반자동화돼 있고(Task1 프롬프트 → `wish-pixelize` → `wish-reel`), ②릴스 운영·③퍼널·④UGC는
여기 절차대로 직접 운영합니다.

---

## 0. KPI (이것만 본다)

- **주간 신규 팔로워** — 릴스 도달의 결과.
- **저장(save) 수** — 알고리즘 부스트의 핵심. 카드/캐러셀이 잘 되는지 신호.
- **프로필 링크 클릭 → 사이트 방문** — 진짜 전환. (측정은 9장 참고)
- **신규 소원 수 / 신규 가입 수** — 애널리틱스 대시보드(`/admin/analytics`)로 확인.

처음 한 달은 팔로워 숫자보다 **저장·공유·링크클릭**에 집중. 도달이 거기서 나옵니다.

## 2. ① 영상(릴) 만들기 — 3단계 파이프라인

흥미로운 소원을 잔잔한 lofi 픽셀 **세로 영상(1080×1920)** 으로 만들어 피드/릴스의 핵심
콘텐츠로 씁니다. Claude Code 스킬로 반자동화돼 있습니다.

- **Task 1 — 원본 장면 생성(외부 AI):** Nano Banana/Midjourney 등에 프롬프트로 lofi 장면을
  생성(Claude가 프롬프트 제공). 후보 몇 장 → 베스트 선택. *(Claude는 이미지를 직접 생성 못 함)*
- **Task 2 — 픽셀화(`wish-pixelize` 스킬):** 고른 원본을 픽셀아트 후보 5종(픽셀크기·팔레트·
  색톤)으로 → 하나 선택.
  ```bash
  .venv/bin/python scripts/pixelize.py --image ~/Downloads/original.png --out-dir instagram_videos/pixelized
  ```
- **Task 3 — 영상+캡션(`wish-reel` 스킬):** 고른 픽셀 이미지 + 소원 ID → 세로 릴 + 한국어
  캡션. 느린 팬·소원 페이드인·무드 입자에 더해, 장면에 맞는 **작은 ambient 모션**(지나가는
  기차·비·눈·창불빛·물결·고양이 꼬리 등)을 Claude가 이미지를 보고 배치합니다.
  ```bash
  export REEL_API_TOKEN=서버와_같은_토큰
  .venv/bin/python scripts/video_anim.py --image <픽셀이미지> --ids 14 59 \
    --fx "twinkle:x=0.05,y=0.4,w=0.9,h=0.25" --out instagram_videos/reel.mp4
  ```

- 보통은 Claude Code에 말로: *"이 이미지로 wish-reel, 소원 14·59. 다리 위로 기차 지나가게, 비 살짝."*
- 고를 때: **보편적·감성적** 소원 우선, 식별 가능한 건 제외(7장 프라이버시 참고).
- 영상은 **무음** — 인스타 앱에서 음악 추가. 출력은 `instagram_videos/`(git 제외).
- 캡션 공식: 소원 한 줄 재인용 → 공감 한 문장 → CTA → 해시태그(`#소원 #소원의나무` …).

## 3. ② 릴스 (도달 엔진 — 주 2~3개)

신규 계정 도달의 80%는 릴스에서 나옵니다. 앱이 시각적으로 예쁘니 화면을 그대로 씁니다.

**포맷 아이디어 (각 7~15초, 잔잔한 음악/트렌딩 오디오):**
1. **반딧불 점등** — 밤 나무에 소원(반딧불)이 하나씩 켜지는 화면 녹화 + "이 소원이 이루어질까요?" 자막.
2. **소원 한 줄 타이핑** — 빈 화면에 소원이 타이핑되며 나타남 → 나무에 걸림.
3. **이번 주 BEST 5** — 카드 5장을 비트에 맞춰 넘기기(저장 유도).
4. **봉안당 무드** — 이루어지지 못한 소원의 추모. 감성·위로 톤(글귀 계정과 궁합).
5. **수능/새해 시즌 버전** (5장).

촬영: 폰 화면 녹화(`tree-of-wishes.fyi` 접속) → 자막·오디오는 인스타 내장 에디터 또는 CapCut.
첫 1초에 후크(질문/강한 소원 한 줄)를 넣을 것.

## 4. ③ 링크 퍼널 (피드 링크는 클릭 불가!)

인스타는 피드/릴스 캡션의 링크를 막습니다. 링크는 **두 곳에서만** 살아납니다.

- **바이오 링크** — 모든 피드/릴스 CTA는 "프로필 링크에서"로 통일.
- **스토리 링크 스티커** — 특정 소원으로 바로:
  `https://tree-of-wishes.fyi/wish/<id>?lang=ko`
  → OG 프리뷰가 예쁘게 떠서 클릭률↑. (이미 다국어 OG 적용됨.)

스토리 루틴(주 3~4회): 소원 1개 소개 + 링크 스티커 + 투표/질문 스티커("당신의 소원은?").

## 5. ④ UGC 루프 (진짜 바이럴 엔진)

사람들이 **자기 소원을 직접 공유**하게 만들고, 좋은 걸 **스토리에 리포스트**합니다.

1. 캠페인 해시태그 지정: **`#소원의나무`**.
2. 사이트에서 소원 공유(Copy Link/OG) → 인스타 스토리에 올리고 계정 태그 유도.
3. 들어온 UGC 중 좋은 것 → 스토리 리포스트 + 감사 코멘트.
4. "내 소원도 올라갈까?" 동기 → 더 많은 공유. (선순환)

게이미피케이션: "이번 주 가장 많은 좋아요를 받은 소원"을 매주 피처링 → 좋아요 경쟁 유발.

## 6. 해시태그 세트 (게시물당 10~15개 혼합)

- 핵심: `#소원` `#소원성취` `#소원의나무`
- 감성/글귀(대형): `#오늘의글귀` `#감성글귀` `#글귀스타그램` `#위로` `#힐링`
- 시즌: `#새해소원` `#수능소원` `#합격기원`
- 영문(글로벌 노출): `#wish #makeawish`

대형·중형·소형 태그를 섞어야 묻히지 않습니다.

## 7. ⚠️ 프라이버시 주의

공개 게시판이라도 인스타 증폭은 노출이 훨씬 큽니다.
- 실명·연락처·특정 인물/사건이 드러나는 소원은 **피처링 금지**.
- 보편적이고 감성적인 소원 위주로 선별.
- 문제 제기가 오면 즉시 내림.

## 9. 측정 (구현됨)

유입 출처 집계가 **이미 적용되어 있습니다.** 바이오/스토리 링크에 `?src=ig` 를 붙이면,
그 링크로 **처음 들어온 방문**이 `ig` 출처로 기록됩니다(일자별 first-touch). 출처별 분포는
관리자 대시보드 `/admin/analytics` 상단 **Traffic sources** 표에서 확인하세요.

- 인스타: `tree-of-wishes.fyi/tree?src=ig`
- 다른 채널도 자유롭게: `?src=blog`, `?src=kakao` 등 (출처별로 나뉘어 집계됨)
- `src` 없는 방문은 `direct` 로 집계.
